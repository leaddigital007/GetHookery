How to use this admin (3-minute read — open this every morning)

Daily routine (Kanban — do this in order):

  1. Open Outreach Kanban. 7 columns: Research → Ready to send → Sent → Follow-up due → Replied → Meeting/DD → Closed. Drag cards left ↔ right to change status.
  2. Take cards from "Ready to send": click the channel pill (form / email / LI / X) on the card to open the destination. Get the draft text via the List view tab (one click away — full copy-able drafts there). Send it. Drag the card into "Sent" — a prompt asks which channel you actually used. Card moves, +7-day follow-up scheduled.
  3. "Research" column contains: persons without a channel (need email/LI/X added), persons without a draft, AND dashed dark-fund cards for funds with no partners on file. Click "+ Add contact" on a fund card or edit a person to fill in their channel. Card auto-promotes to "Ready".
  4. "Follow-up due" appears after 7 days. Send the nudge, then drag either back to "Sent" (resets +7d) or forward to "Replied" if they answered.
  5. "Replied" → "Meeting/DD" when a call is booked. "Meeting/DD" → "Closed" when the deal is won, lost, or they pass.
  6. The List view (worklist) is for getting the actual draft text: same data, vertical layout, with full copy-able drafts and explicit Mark sent buttons. Use it when you want to see the long email body before sending.

Where everything lives (cheat-sheet):

  • Worklist — today's actionable queue. Use this 90% of the time.
  • Sent log — chronological list of every message I have sent. This answers "did I already write to X?" and "what is overdue?".
  • Pipeline dashboard — aggregate counters and saved searches.
  • Persons admin — edit a single contact's email / Twitter / LinkedIn, or use bulk actions on a filtered list.
  • Funds admin — edit fund-level info (submission_url, contact_email), or add/edit Persons inline from a fund.
  • + Add new contact — Person form. Fund field has autocomplete. Use this when you discover a new partner manually.

Hard rules — do not break:

  • Never edit the LLM-drafted text in outreach_text from the worklist without copy-pasting first. The drafts cache there for reference.
  • Never click "Mark sent" before you actually sent the message.
  • If you replied or got a reply, click "Mark replied" — otherwise the row stays in "Awaiting reply" forever.
  • The drafts contain factual claims about Igor (solo founder, $1M pre-seed, $10M cap, 659 signups, $202 MRR). Verify the hook before sending, especially personalisation lines about the fund's portfolio.
