How to use this admin (3-minute read — open this every morning)

Daily routine (do this in order):

  1. Open Daily Worklist. Top bucket "Today: primary contacts" is the queue you process first. Each card has a copy-able draft, the channel button (X / LinkedIn / email / submission form), and a "Mark sent" button.
  2. For each row: read the hook, copy the right draft (X DM / LI DM / Email — depending on what is suggested), open the channel link, paste, send. Then come back and click Mark sent with the channel you actually used. That timestamps the action and auto-schedules a +7-day follow-up.
  3. "Funds without partner contacts" bucket = funds we like but where we do not have a single Person yet. Click Open fund or + Add contact to add a partner manually (1-2 names from their /team page is enough).
  4. "Funds with persons but no channel" bucket = we know the partner name but no Twitter / LinkedIn / email. Click the partner, paste their LI URL or X handle into the Person edit form, save. They auto-promote into "Today" buckets.
  5. Follow-ups overdue bucket appears after 7 days. Click "Followed up" on the row after you actually send a nudge.
  6. Replied bucket: when someone answers, click Mark replied. Then move them through pipeline stages from the Person admin (Contacted → Replied → Meeting → DD → Term sheet → Closed).

Where everything lives (cheat-sheet):

  • Worklist — today's actionable queue. Use this 90% of the time.
  • Sent log — chronological list of every message I have sent. This answers "did I already write to X?" and "what is overdue?".
  • Pipeline dashboard — aggregate counters and saved searches.
  • Persons admin — edit a single contact's email / Twitter / LinkedIn, or use bulk actions on a filtered list.
  • Funds admin — edit fund-level info (submission_url, contact_email), or add/edit Persons inline from a fund.
  • + Add new contact — Person form. Fund field has autocomplete. Use this when you discover a new partner manually.

Hard rules — do not break:

  • Never edit the LLM-drafted text in outreach_text from the worklist without copy-pasting first. The drafts cache there for reference.
  • Never click "Mark sent" before you actually sent the message.
  • If you replied or got a reply, click "Mark replied" — otherwise the row stays in "Awaiting reply" forever.
  • The drafts contain factual claims about Igor (solo founder, $1M pre-seed, $10M cap, 659 signups, $202 MRR). Verify the hook before sending, especially personalisation lines about the fund's portfolio.
